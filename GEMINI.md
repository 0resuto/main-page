# 🤖 Инструкции для AI Агентов (Project Manifest)

Добро пожаловать в проект! Это современное веб-приложение (Landing Page / Портфолио), построенное с упором на производительность, строгую типизацию и плавные анимации.

При генерации или изменении кода, пожалуйста, **строго следуйте** приведенным ниже правилам.

## 🛠 Стек технологий
- **Фреймворк:** Next.js 15+ (исключительно App Router).
- **Язык:** TypeScript (строгая типизация, избегать `any`).
- **Стилизация:** Tailwind CSS + CSS переменные для брендовых цветов.
- **Анимации:** Framer Motion (`motion/react`).
- **Иконки:** Lucide React.

## 🏗 Архитектура и Разделение (Server vs Client)
1. **Server Components по умолчанию:** Все страницы (`app/page.tsx`) и слои (`app/layout.tsx`) должны быть **серверными компонентами** (Server Components). Не используйте `"use client"` в корневых файлах `app/`.
2. **Client Components для UI:** Интерактивные элементы, анимации (Framer Motion), стейты (`useState`, `useEffect`) и слушатели событий (IntersectionObserver, хуки скролла) должны быть вынесены в папку `components/` и начинаться с директивы `"use client"`.
3. **Сериализация пропсов:**
   Серверные компоненты **не могут** передавать функции или классы в клиентские компоненты. 
   - *Неправильно:* `icon={LucideIcon}` (ошибка сериализации).
   - *Правильно:* `icon={<LucideIcon size={24} />}` (передача `ReactNode`).

## 🎨 Дизайн-система и Стилизация (Glassmorphism)
Проект использует дизайн в стиле "Glassmorphism" (эффект матового стекла) на темном фоне.

- **Цветовая палитра (Tailwind):**
  - `brand-bg` — основной темный фон.
  - `brand-60` — фон карточек и панелей.
  - `brand-30` — акцентный цвет (красный/основной выделяющий).
  - `brand-10` — цвет основного текста (светлый).
- **Эффект стекла:**
  Используется сочетание классов `glass backdrop-blur-md bg-brand-60/30 border border-brand-10/10`. *Никогда не используйте отрицательный z-index для слоев со стеклом совместно с 3D-трансформациями.*
- **Взаимодействие (Hover):**
  Карточки и кликабельные элементы должны плавно "всплывать": `hover:-translate-y-2 hover:shadow-2xl transition-all duration-300`. Не используйте `hover:scale` для блоков с текстом во избежание "дребезжания" пикселей.

## ⚡ Производительность (Performance & UX)
1. **Скелетоны (Loading UI):**
   Для асинхронной загрузки данных в клиентских компонентах (например, GitHub API) всегда используйте скелетоны (`animate-pulse`), повторяющие структуру реального контента, чтобы избежать скачков верстки (Layout Shift). Для серверной загрузки используйте `app/loading.tsx`.
2. **Ленивая загрузка (Lazy Loading):**
   Тяжелые компоненты, которые не нужны при первой отрисовке (например, модальные окна), должны загружаться динамически с помощью `next/dynamic`:
   ```tsx
   const PrivacyModal = dynamic(() => import("./modals/PrivacyModal"));
   ```
3. **Изоляция рендеров:**
   Стейты `isMenuOpen`, `isScrolled` и другие UI-триггеры должны жить в своих локальных компонентах (например, `Header.tsx`), чтобы не вызывать перерисовку всей страницы.
4. **Высокочастотные анимации:**
   Избегайте `useState` для 60fps анимаций (например, аудио-визуализаторы или прогресс-бары). Используйте `useRef` и `requestAnimationFrame` для прямых манипуляций DOM (`ref.current.style.height`), чтобы не "душить" React частыми рендерами.
5. **Плавный скролл (Lenis) и локальные контейнеры:**
   Для прокручиваемых списков внутри страницы используйте атрибут `data-lenis-prevent="true"` и класс `overscroll-contain`. Для лучшего UX включайте этот атрибут по событию `onMouseMove` и выключайте по `onMouseLeave`, чтобы не перехватывать скролл, если пользователь просто прокручивает страницу мимо блока.

## 🌐 Работа с данными (API)
1. Если данные извлекаются на клиенте (через `useEffect`), **обязательно** используйте паттерн `isMounted` (или AbortController), чтобы предотвратить обновления стейта в размонтированном компоненте и избежать утечек памяти:
   ```typescript
   useEffect(() => {
     let isMounted = true;
     const fetchData = async () => {
       try {
         const res = await fetch(...);
         if (!isMounted) return;
         // set state...
       } catch (err) {}
     };
     fetchData();
     return () => { isMounted = false; };
   }, []);
   ```
2. Корректно обрабатывайте ошибки сети (`!res.ok`) и выводите пользователю резервный UI (Fallback Error UI) в стиле проекта.

## 🎵 Медиа и Web Audio API
1. **CORS Политика:** Если медиа-поток используется для анализа (`createMediaElementSource`), обязательно добавляйте атрибут `crossOrigin="anonymous"` к тегу `<audio>`/`<video>`, чтобы браузер не блокировал доступ к данным частот.
2. **Визуализация и Громкость:** При работе с `AnalyserNode` всегда оставляйте громкость самого медиа-элемента на `1` (100%), чтобы визуализатор реагировал на звук корректно. Регулируйте итоговую громкость для пользователя с помощью промежуточного узла `GainNode` *после* анализатора.
